# Monesha Portfolio Website

An editorial-inspired UI/UX portfolio website exploring the intersection of design, storytelling, and frontend development.

## Overview

This project is the first public deployment (v0.1) of my personal portfolio website.

Originally designed in Figma and later refined through iterative frontend development, the website combines a newspaper-inspired visual identity with interactive web experiences.

The project involved:
- UI/UX design refinement
- Frontend implementation
- Responsiveness testing
- Lighthouse performance auditing
- Git/GitHub version control
- Vercel deployment
- Contact form integration using Web3Forms

## Live Website

https://monesha-uiux-portfolio.vercel.app/

## Features

- Editorial / newspaper-inspired visual direction
- Responsive layouts across devices
- Interactive navigation and UI elements
- Design Deck showcase section
- Creative Footnotes section
- Contact form with Web3Forms integration
- Public deployment through Vercel
